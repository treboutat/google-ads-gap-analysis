# Test: Immature recent days and stage-valued conversions

All account identifiers, terms and figures below are synthetic.

## Input

"What tests could earn more value for the rest of the month?" asked on October 25. B2B account on Maximize conversion value; values are $1 lead, $250 MQL, $500 SQL, $2,500 opportunity. The user has not stated a conversion lag. A competitor-alternatives theme shows $4,100 spend and 22 conversions worth $33,000 over 90 days, but 15 of those conversions are $1 leads from the last two weeks. A generic theme shows 40 conversions, all $1.

## Expected decisions

- States lag as unknown, treats the last 14 days as pending, and judges themes on the mature window.
- The generic theme is not a winner on $1 conversions; the alternatives theme is judged on its mature value per conversion.
- Asks once for the lag and the value schedule confirmation; continues the rest.
- Tests & reallocation: 3–5 tests; prefers clear-mismatch negatives and routing that can read within the lag; says which results will not be readable by month end; any budget or target shift is a recommendation for a separate budget decision.

## Failure cases

Counting $1 leads as proof a keyword works; judging October results as mature; deciding a budget shift inside this skill.
